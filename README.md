# 🛒 Blinkit Sales Analysis Using Python & Pandas

## 📌 Project Overview

This project performs an exploratory data analysis of Blinkit retail sales data using **Python and Pandas**.

The objective is to analyze sales performance, product categories, fat content, outlet characteristics, and customer ratings to identify useful business insights from the dataset.

---

## 🎯 Project Objectives

* Analyze overall sales performance.
* Understand sales across different item types.
* Compare sales based on item fat content.
* Analyze sales by outlet location and size.
* Study sales trends based on outlet establishment year.
* Calculate important business KPIs.
* Create meaningful visualizations using Python.

---

## 📊 Key Performance Indicators (KPIs)

The analysis focuses on the following KPIs:

* **Total Sales** – Overall revenue generated from items sold.
* **Average Sales** – Average revenue per sale.
* **Number of Items** – Total number of items sold.
* **Average Rating** – Average customer rating of the items.

---

## 📈 Analysis & Visualizations

The project analyzes the following areas:

### 1. Total Sales by Fat Content

Analyzes how total sales vary between different item fat-content categories.

### 2. Total Sales by Item Type

Compares sales performance across different product categories.

### 3. Fat Content by Outlet

Compares sales across outlets while considering item fat content.

### 4. Total Sales by Outlet Establishment Year

Analyzes sales performance based on the year an outlet was established.

### 5. Sales by Outlet Size

Examines the relationship between outlet size and total sales.

### 6. Sales by Outlet Location

Analyzes the distribution of sales across different outlet locations.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/blinkit-pandas-analysis.git
```

### 2. Navigate to the Project

```bash
cd blinkit-pandas-analysis
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Open Jupyter Notebook

```bash
jupyter notebook
```

Then open:

```text
notebooks/blinkit_analysis.ipynb
```

Run the notebook cells from top to bottom.
